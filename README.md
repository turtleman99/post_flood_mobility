# Socioeconomic Gradients in Post-Flood Mobility: Evidence from Two Secondary Cities in Monsoon Asia

This is the official repository for *Socioeconomic Gradients in Post-Flood Mobility: Evidence from Two Secondary Cities in Monsoon Asia*.

## Abstract
Disaster mobility research in high-income, industrialized settings has emphasized socioeconomic factors in population displacement: communities with greater resources typically experience population inflows and faster recovery, while disadvantaged areas suffer longer displacement and population loss. Whether these patterns hold in rapidly urbanizing Global South cities remains unclear. This study examines neighborhood-level changes in detected device presence (used here as a proxy for short-term population presence) after floods in Pune, India, and Bandung, Indonesia, using NetMob 2024 mobile phone data. We integrate satellite-derived flood maps to distinguish flooded from non-flooded areas, and cluster device-presence trajectories over the 30 days before and after each event's onset, examining how flood exposure and neighborhood deprivation relate to these changes. In both cities, less deprived neighborhoods experienced increases in detected device presence, while more deprived areas experienced decreases in detected device presence, consistent with resource-seeking interpretations documented in North American and European disaster research. The cities differed, however, in how deprivation relates to flood exposure: in Pune, more deprived flooded neighborhoods showed suggestive evidence of disproportionately larger decreases in detected device presence than similarly deprived non-flooded neighborhoods; no comparable interaction was observed in Bandung. These findings suggest that economic considerations are associated with post-flood device-presence changes in South and Southeast Asian cities in ways that parallel high-income contexts, while local conditions, especially neighborhood deprivation, introduce important variation.

## Usage
+ To install the required Python packages, run the following commands,
  ```
  conda env create -f environment.yml
  conda activate netmob24
  ```

+ Download the Global Gridded Relative Deprivation Index (GRDI) from this [link](https://www.earthdata.nasa.gov/data/catalog/sedac-ciesin-sedac-pmp-grdi-2010-2020-1.00), and put in [./data/inequality_data_grdi](./data/inequality_data_grdi).

+ Download the Dartmouth Flood Observatory flood polygons from this [link](https://floodobservatory.colorado.edu/), and put in `./data/FloodArchive_NASA`.

+ Download the ASTER Global Digital Elevation Model V3 from this [link](https://doi.org/10.5067/ASTER/ASTGTM.003), and put the mosaicked raster in `./data/elevation`.

+ All other data needed to reproduce the figures are in [./data](./data).

+ All scripts to generate the figures in the main paper are in [./scripts](./scripts). See [./scripts/README.md](./scripts/README.md) for the order the scripts run in and what each one reads and produces.

+ Figures generated by these scripts are in [./outputs](./outputs).
