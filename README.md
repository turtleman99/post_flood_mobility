# Neighborhood Deprivation Shapes Post-Flood Population Losses in Pune and Bandung

This is the official repository for *Neighborhood Deprivation Shapes Post-Flood Population Losses in Pune and Bandung* by Sukie Xiuqi Yang, Guangyuan Weng, Shiyue Cui, Zhicong Chen, and Catherine Chen.

## Abstract
Disaster research in high-income settings shows that better-resourced communities see population inflows and faster recovery, while disadvantaged communities suffer prolonged population loss. Whether this pattern holds in rapidly urbanizing cities of the Global South remains unclear. Here we show, using mobile phone data from Pune, India, and Bandung, Indonesia, how neighborhood-level changes in phone presence, a proxy for short-term population movement, relate to flooding and neighborhood deprivation. We combine satellite-derived flood maps with phone records to compare flooded and non-flooded areas over the 30 days around each flood. In both cities, less deprived neighborhoods see phone presence rise after flooding, while more deprived neighborhoods see it fall, consistent with resource-seeking interpretations documented in North American and European disaster research. The cities differed, however, in how deprivation relates to flood exposure: in Pune, more deprived flooded neighborhoods showed suggestive evidence of disproportionately larger decreases in detected device presence than similarly deprived non-flooded neighborhoods; no comparable interaction was observed in Bandung. Economic considerations are associated with post-flood device-presence changes in South and Southeast Asian cities in ways that parallel high-income contexts, though local context adds variation.

## Usage
+ To install the required Python packages, run the following commands,
  ```
  conda env create -f environment.yml
  conda activate netmob24
  ```

+ Download the Global Gridded Relative Deprivation Index (GRDI) from this [link](https://www.earthdata.nasa.gov/data/catalog/sedac-ciesin-sedac-pmp-grdi-2010-2020-1.00), and put in [./data/inequality_data_grdi](./data/inequality_data_grdi).

+ Download the Dartmouth Flood Observatory flood polygons from this [link](https://floodobservatory.colorado.edu/), and put in `./data/FloodArchive_NASA`.

+ Download the ASTER Global Digital Elevation Model V3 from this [link](https://doi.org/10.5067/ASTER/ASTGTM.003), and put the mosaicked raster in `./data/elevation`.

+ All other data needed to reproduce the figures are in [./data](./data).

+ All scripts to generate the figures in the main paper are in [./scripts](./scripts). See [./scripts/README.md](./scripts/README.md) for the order the scripts run in and what each one reads and produces.

+ Figures generated by these scripts are in [./outputs](./outputs).
